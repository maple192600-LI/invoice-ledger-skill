# 发票台账本地化采集

**把本地 PDF、图片和扫描发票批量识别成一份持续使用的 Excel 发票采集台账。**

<img src="assets/banner.png" alt="发票台账本地化采集" width="100%">

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

## 能为你做什么

| 使用场景 | 处理结果 |
|---|---|
| **一个文件夹里有很多发票** | 批量读取文件，提取票面信息和商品明细，统一写入一份 Excel 台账 |
| **一个 PDF 里合并了多张发票** | 逐页识别发票号码和购销双方，不同发票分别生成发票单元 |
| **同一张发票有多页明细** | 确认发票身份一致后合并页面，保留全部商品和服务明细 |
| **发票是图片或扫描件** | 自动使用本地 OCR 识别图片和图片型 PDF |
| **每个月都要继续记账** | 首次选择保存位置后，后续批次持续写入同一份台账 |
| **担心重复录入或覆盖旧数据** | 写入前检查疑似重复，只追加新数据，不覆盖已有内容 |
| **需要检查识别异常** | 低置信度、未支持票种和未写入原因集中记录在“识别提示”工作表 |

**适合谁用**：企业财务、会计、出纳、报销审核人员，以及需要批量整理发票的个人和小型团队。

## 快速开始

安装后直接告诉你的 agent：

> “把 `D:\待报销发票` 里的发票识别并写入台账。”

> “识别这个多页 PDF，每张发票分别入账。”

> “继续写入我上次选择的发票采集台账，不要覆盖原有数据。”

> “检查这批发票有哪些没有写入，并告诉我原因。”

## 处理流程

```text
选择台账保存位置
    ↓
读取单个文件或整个文件夹
    ↓
文本发票直接解析，图片和扫描件使用本地 OCR
    ↓
逐页识别发票号码、票面信息和商品明细
    ↓
多页多票自动拆分，确认属于同一张发票的跨页明细自动合并
    ↓
按票种校验并检查重复
    ↓
追加写入同一份 Excel 台账
```

## 核心能力

### 多页 PDF 自动分票

- 每一页先独立识别发票号码、开票日期、购买方、销售方和金额信息。
- 相邻页面发票号码不同，拆分成不同发票单元。
- 发票号码相同，并确认后续页面属于同一张发票的跨页明细时合并。
- 无法确认页面关系时保持拆分，不把整份 PDF 强行归为一张发票。
- 合并跨页发票时保留各页全部商品和服务明细。

### 持续写入同一份台账

- 首次启用时询问发票采集台账的保存位置。
- 可以选择文件夹，也可以直接提供已有 `.xlsx` 文件。
- 后续识别持续写入已经选择的台账。
- 根目录 `发票采集台账.xlsx` 只作为空白母版。
- 目标台账不存在时复制母版；目标台账已存在时校验后续写。
- 禁止覆盖、清空或替换已有数据。

### 重复检查和异常集中

- 写入前根据发票身份和明细内容检查疑似重复。
- 已经存在的数据不重复写入。
- 没有识别出的字段保持为空，不编造发票号码或购销双方。
- 需要人工确认的内容集中记录，不混入正常识别结果。

## Excel 输出

所有发票持续写入同一份 Excel 文件，不会一个 PDF 生成一个 Excel。

| 工作表 | 内容 |
|---|---|
| **发票信息采集** | 发票号码、数电发票号码、开票日期、购买方、销售方、金额、税额、价税合计和商品明细 |
| **发票基础信息** | 每个发票单元的票种、来源文件、页码范围和处理状态 |
| **识别提示** | 低置信度、疑似重复、未支持票种、未写入原因和人工复核提示 |

采集表标题格式保持统一，列宽根据实际内容自动调整，写入后可以直接查看。

## 安装

本 Skill 可在 Claude Code、Codex、Cursor、Gemini CLI 等 agent 中使用。

简要流程：

1. 克隆仓库并挂载到你的 agent 的 skills 目录。
2. 运行 `python scripts/install_skill_env.py --ocr auto --ledger <台账位置>` 创建本地环境。
3. 重启 agent，首次启用时询问台账保存位置。

已有台账会直接沿用，不会覆盖。

## 运行环境

- Windows
- Python 3.11+
- PyMuPDF
- openpyxl
- PyYAML
- Pydantic
- PaddleOCR
- NVIDIA GPU 可用时自动使用 GPU，否则使用 CPU

## 使用边界

- 暂不支持 OFD。请从电子税务局税务数字账户下载 PDF 版式文件后再识别。
- OCR 结果会受到图片清晰度、倾斜、遮挡和票面版式影响，低置信度内容会进入“识别提示”。
- 本项目负责发票信息采集和台账整理，不代替税务申报、抵扣判断或票据真伪查验。
- 发票内容在本机处理，不依赖在线 OCR 服务。
