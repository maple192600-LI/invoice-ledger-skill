# 不动产经营租赁发票

- 权威依据：税务发票票面正式标签，以及本轮用户确认的台账业务口径
- 工作结果：识别不动产经营租赁发票并写入通用发票台账，专属信息默认不写入 Excel
- 建模样本：2 份受控私有 PDF，分别为停车费和房租
- 建模日期：2026-07-27

| 当前不采集 | 票面外的产权、面积、地址和租赁信息 | 无 | 不从其他资料补写 |

## 4. 明细和备注

- 明细单位：票面列示的经营租赁项目。
- 直接输出列：沿用通用发票台账列。
- 派生字段及公式：无。
- 备注格式：默认不生成不动产专属备注。
- 空值规则：缺失值不补写、不猜测。
- 多条或多页规则：保留通用明细；专属信息继续只作内部控制。
